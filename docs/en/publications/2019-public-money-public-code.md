## About the Translation

This is the official Brazilian Portuguese translation of the *Public Money? Public Code!* campaign conceived by the Free Software Foundation Europe (FSFE).

The initiative argues that software funded with public money should have its source code released under a free software or open source license. When public resources are used to fund the technology that runs government infrastructure, it is essential that society has the right to audit, use, share, and improve that same technology.

We at LabLivre are proud to help make this knowledge available in Portuguese.
